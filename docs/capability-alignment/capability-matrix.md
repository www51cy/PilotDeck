## 状态变更规则

1. 状态变化必须同时更新证据位置和未覆盖范围。
2. 新发现不得通过重写历史结论消失；应追加处置记录。
3. 工作区存在外来修改时，证据必须注明其适用范围，不能笼统归因于 HEAD。
4. 能力完成不等于阶段完成；阶段完成还要求对应真实任务和独立复核闭合。
